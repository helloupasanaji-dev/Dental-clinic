# 10 Dentist Website Examples & Design Ideas

A modern, responsive showcase website featuring **10 curated dentist website examples**, complete with UX design breakdowns, color palettes, typography pairings, interactive filtering, a dental website UX audit checklist, and an interactive practice persona matcher.

## Features

- **Exact Content & Headings**:
  - Title: *10 Dentist Website Examples & Design Ideas*
  - Subtitle: *Looking for inspiration for a dental practice website? These real dentist websites show different ways to build trust, simplify booking, present services, reduce patient anxiety, and create a memorable dental brand.*
  - Metadata: *Updated October 2026 • 10 examples*
- **10 Real Practice Breakdowns**:
  1. **Grand Street Dental** (Brooklyn, NY) — Editorial & Luxury
  2. **Tend** (hellotend.com) — Tech & Frictionless
  3. **Zen Dental Studio** (San Francisco / Mountain View) — Calm & Anxiety-Free
  4. **Dental Design SD** (San Diego, CA) — Tech & Cosmetic Precision
  5. **The A.B.C. Smile** (Denver, CO) — Friendly, Human & Honest
  6. **Dentologie** (Chicago, IL) — Urban, Chic & Community
  7. **Gentry Dentistry** (Charlotte, NC) — Boutique, Luxury & Storytelling
  8. **BEAM Pediatric Dental Studio** (Nashville, TN) — Playful, Cheerful & Kids
  9. **Austin Dental Company** (Austin, TX) — Local Warmth & Modern
  10. **Prism Oral Surgery** (Seattle, WA) — Specialized & Surgical Authority
- **Interactive Capabilities**:
  - Live category filter tabs (All, Editorial, Tech, Calm, Pediatric, Specialist)
  - Real-time search by practice name, city, tag, or style
  - Color palette swatch previews with 1-click HEX code copying to clipboard
  - Interactive "Inspect Design & UX" modal with complete case study analysis
  - Save to favorites / bookmarks saved locally via `localStorage`
  - Interactive **Dental Website UX Audit Checklist** with real-time score calculation
  - **Practice Persona & Style Matcher** recommending tailored palettes, headlines, and layouts for different dental specialties

## How to View the Website

### Option 1: Direct Browser Open
Double-click `index.html` or right-click `index.html` and choose **Open with > Google Chrome** (or Edge/Brave/Firefox).

### Option 2: Run with Node.js
If you have Node.js installed, open PowerShell in this directory and run:
```powershell
npx serve
```
Then visit the localhost URL displayed in the terminal (e.g., `http://localhost:3000`).
